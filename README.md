# Purnima Career Studio - Portfolio Website

A professional portfolio website for a Resume & Career Profile Specialist, built with React, TypeScript, and Vite.

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Modern CSS** - Clean, responsive styling

## Features

- ✅ Hero Section
- ✅ About Me
- ✅ Services
- ✅ Why Choose Me
- ✅ Proof / Results
- ✅ Process
- ✅ Contact / CTA

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The site will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
├── components/      # Individual section components
├── pages/          # Page components
├── App.tsx         # Main app component
├── main.tsx        # Entry point
└── index.css       # Global styles
```
