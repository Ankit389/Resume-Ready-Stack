# Image Setup Instructions

To display Purnima Rani's photo in the About section:

1. Save the image file as `purnima-rani.jpg` in this `public` folder
2. The image should be a professional portrait photo
3. Recommended dimensions: 350x350px or larger (square aspect ratio works best)
4. Supported formats: JPG, PNG, or WebP

The website will automatically display the image once it's placed in this folder.
